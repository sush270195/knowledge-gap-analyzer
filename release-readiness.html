🤖 Agentforce & Einstein AI

22 changes · High TSE Impact
  • GA Agentforce 3.0 — Autonomous Agent Orchestration
    Agents can now spawn sub-agents and orchestrate multi-step workflows autonomously. Replaces manual flow handoffs in many service scenarios.
    Service CloudSales Cloud
  • GA Einstein Copilot — Unified Prompt Studio
    Single interface to author, test, and deploy prompts across all Einstein features. Deprecates separate copilot builder tools.
    Migration Required
  • Beta Agent Studio — No-Code Agent Builder
    Declarative builder for creating Agentforce agents without Apex. Beta customers get early access with Winter '27 sandbox preview.
    Beta
  • Changed Einstein Case Classification — Model Updates
    New multi-label classification model increases accuracy but changes field-mapping behavior. Existing configs auto-migrate.
    Service CloudReview Needed
  • New Predictive Forecasting v3 — Territory AI
    AI-powered forecasting now factors in territory changes and historical win rates at quota tier. New dashboards included.
    Sales Cloud

⚡ Flow & Automation

18 changes · Critical Updates included
  • GA Flow Orchestration — Cross-Object Work Queues
    Flow Orchestration now supports routing work items across objects using Omni-Channel work queues. Replaces legacy process automation patterns.
    Service CloudFlow
  • Changed User Permissions on API Callout Flows
    Flows that make Apex callouts will now enforce running-user permissions. System mode must be explicitly declared. Auto-activates Oct 10.
    Breaking ChangeAuto-Activates Oct 10
  • New Screen Flow — Conditional Sections Component
    New native component to conditionally show/hide sections in Screen Flows without custom LWC. Supports display conditions and lazy loading.
    Flow
  • Changed Flow Interview State Expiration — 30 Days
    Long-paused screen flow interviews will now expire after 30 days (previously 90). Affects multi-day approval workflows built on Screen Flow.
    Review Needed
  • Retiring Process Builder — Final Deprecation Notice
    Process Builder enters read-only mode in Winter '27. No new processes can be created. Migration to Flow required before Summer '27.
    Action Required

💼 Sales Cloud

38 changes
  • GA Revenue Cloud — Unified Billing
    Unified Billing merges CPQ billing and Subscription Management into one data model. Separate objects will be retired in Spring '27.
    Sales CloudMigration Path
  • Changed Opportunity Splits — New Split Types
    Two new split types (Partner Credit, Overlay) added. Custom split type limits increased to 5. Existing splits unaffected.
    Sales Cloud
  • New Deal Rooms — Slack Integration
    Deal Rooms now create dedicated Slack channels automatically on opportunity stage advancement. Requires Slack integration enabled.
    Sales CloudNew
  • Changed Forecasting — Quota Hierarchy Changes
    Quota rollup now respects territory hierarchy in addition to user hierarchy. May change existing forecast totals for split-territory orgs.
    Review Needed

  • GA Omni-Channel — Skills-Based Routing v2

    Service CloudValidate
  • New Digital Engagement — WhatsApp Business v2

    Service CloudOpportunity
  • Changed Case Teams — Granular Role Permissions

🔧 Platform & Core

14 changes · Security focus
  • Critical My Domain — Mandatory for All Orgs
    Orgs without My Domain enabled will have it auto-activated with Winter '27. Login URLs will change. Communicate to all affected customers.
    Breaking ChangeAuto-Activates Oct 10
  • Changed Apex — Async Governor Limit Tightening
    Total SOQL queries in async Apex reduced from 200 to 150 per transaction in batch contexts. Affects custom batch integrations.
    ApexReview Needed
  • Retiring LWC Deprecated APIs Removal
    APIs marked deprecated in Summer '25 are now removed: lightning-navigation legacy params, force:* component events (partial).
    LWCAction Required
  • New User Permission Sets — Assignment Expiration
    Permission Set assignments can now be given an expiration date. New PermissionSetAssignment field: ExpirationDate.
    Security

📊 Data Cloud & Analytics

11 changes
  • GA Data Cloud — Unified Profiles in Service Console
    Unified Customer Profiles from Data Cloud now surface natively in Service Console without custom configuration. Requires Data Cloud license.
    Data CloudService Cloud
  • New Data Cloud — Zero-Copy Integration with Snowflake
    Data doesn't need to move to be segmented — query Snowflake tables directly from Data Cloud without ETL. Generally available.
    Data Cloud
  • Changed Tableau — Embedded Analytics Engine
    Tableau Embedded replaces CRM Analytics (Einstein Analytics) as the default analytics layer. Existing dashboards auto-migrated with fidelity review recommended.

Updates Auto-Activating Oct 10 (Blockers)

Must test in sandbox before this date
  • BLOCKER  My Domain — Auto-Enable for All Orgs
    Impact: Login URLs will change for orgs without custom domain. Bookmark and SSO configurations break. Affects ~12% of our customer base.
    TSE Action: Pre-emptively flag all affected accounts. KA refresh needed: "My Domain: What Changes and How to Update SSO"
    In Progress — Owner: Security Pod
  • BLOCKER  Flow User Permissions on API Callouts
    Impact: Flows using external callouts in System Mode will fail unless explicitly re-declared. High case volume expected from integration-heavy customers.
    TSE Action: Prepare runbook for "Flow callout permission errors after Winter '27". Proactive health-check guide needed.
    In Progress — Owner: Automation Pod
  • BLOCKER  Classic Email Composer Retirement
    Impact: Custom email templates built on the classic composer will be inoperable. Affects Case management workflows with inline HTML templates.
    TSE Action: New KA needed: "Migrating Classic Email Templates to Lightning for Cases".
    Not Started — Owner: Service Cloud Pod

Updates Auto-Activating Nov 14 (Production GA)

  • Medium Restrict Cross-Org Data Sharing
    Orgs using cross-org sharing patterns (External Data Sources, OData) must explicitly grant sharing. Affects multi-org architectures.
    Reviewed — Runbook drafted
  • Medium Einstein AI Features Default Opt-In
    New Einstein features will be enabled by default for all eligible orgs. Customers must explicitly opt-out. Expect questions on what changed.
    Planned — KA update in backlog
  • Medium Apex Async SOQL Limit: 200→150
    Batch Apex jobs that hit exactly 200 queries per transaction will now fail. Affects orgs with tight batch implementations.
    Planned — Impact analysis underway
  • Low LWC Legacy API Removal
    force:navigateToSObject and related legacy events fully removed. Customers using unmanaged packages with these APIs will get errors.
    Reviewed — KA updated
  • Low Flow Interview Expiration: 90d→30d
    Paused Screen Flow interviews expire after 30 days. Only affects multi-day approval-style screen flows.
    Done — Documentation complete
