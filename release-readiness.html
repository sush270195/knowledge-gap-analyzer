Automation and Flow

Click any item for details
  • Breaking Flow User Permissions on API Callouts ›
    Flows making external API callouts will now enforce running-user permissions. System mode must be explicitly declared. Auto-activates Oct 10.
    High ImpactAuto Oct 10
  • Retiring Process Builder — Read-Only Mode ›
    No new processes can be created in Winter '27. Existing processes still run. Full retirement Summer '27.
    Action Required
  • GA Flow Orchestration — Sales Object Support ›
    Flow Orchestration now natively supports Opportunity, Lead, and Account as orchestration objects.
    Low Impact
  • Changed Flow Interview Expiration: 90d to 30d ›
    Paused Screen Flow interviews expire after 30 days. Affects multi-day approval-style Sales flows.
    Medium Impact

Revenue Cloud and CPQ

Click any item for details
  • GA Revenue Cloud — Unified Billing ›
    CPQ Billing and Subscription Management merge into one data model. Legacy billing objects retire in Spring '27.
    High ImpactMigration Path
  • Changed CPQ — Revenue Schedule Recalculation ›
    Revenue schedule recalculation now runs asynchronously for large quote line groups.
    Medium Impact
  • Changed Subscription Management — Asset Lifecycle ›
    New asset lifecycle states added: Suspended and Pending Cancellation. Affects existing automation on asset status.
    Medium Impact

Einstein and AI

  • GA Agentforce 3.0 — Sales Autonomous Agents ›
    Sales agents can autonomously qualify leads, update CRM records, and schedule follow-ups.
    Enablement Needed
  • GA Einstein Copilot — Unified Prompt Studio ›
    Single interface to author, test, and deploy prompts across all Einstein features. Separate tools deprecated.
    Medium ImpactMigration
  • New Predictive Forecasting v3 — Territory AI ›
    AI-powered forecasting factors in territory changes and historical win rates at quota tier.
    New Feature

Security and Platform

Click any item for details
  • Breaking My Domain — Mandatory for All Orgs ›
    Orgs without My Domain will have it auto-activated. Login URLs and SSO configs will break.
    High ImpactAuto Oct 10
  • Changed Apex Async SOQL Limit: 200 to 150 ›
    Total SOQL queries in async Apex batch contexts reduced from 200 to 150 per transaction.
    Medium Impact
  • New Permission Set Assignment Expiration ›
    Permission Set assignments now support an ExpirationDate field. Assignments auto-revoke at expiration.
    Low Impact
